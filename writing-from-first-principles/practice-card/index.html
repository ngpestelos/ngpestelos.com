5. Practice Card

One page to keep at the desk. Test from the top. Fix from the bottom.

The twelve tests

Reading    Map            before the read: one line on the expected claim and what would change your mind
           Paragraph      after each paragraph: which objection, and evidence / mechanism / both / neither
           Production     without the page: claim, two supports, one objection, under a minute

Essay      First-sentence first sentences alone carry the argument
           Shuffle        reorder the paragraphs; someone must notice
           Deletion       remove any one paragraph; the chain must break

Paragraph  Summary        one sentence; "and" means split
           Underline      first noun phrase of each sentence points back to the page
           Pair           last sentence + next first sentence read as consecutive

Sentence   Spine          the subject can act; the verb is an action
           Last-words     the final three words are the point
           Loss           each word: what is lost if it goes

Order

Test top-down. Essay tests on the whole. Paragraph tests on each block. Sentence tests only on the sentences you reread.

Fix bottom-up. A failed essay test is usually one paragraph with the wrong first sentence. A failed paragraph test is usually one sentence with no spine. Fix the smallest thing that makes the higher test pass, then run the higher test again.

The four build procedures

Reading    Question, Map, Operators, Read, Restate, Reproduce, Object, Keep
Essay      Claim, Cost, Objections, Paragraphs, Close, Opening, Title, Trim
Paragraph  Claim, Questions, Evidence, Mechanism, Shape, Hand-off, Strike
Sentence   Thought, Actor, Verb, Distance, Known, New, Cut

Write the opening last. Write the two questions down. Run the sentence procedure only on the sentence you reread twice.

The delete-only pass

Adds nothing. Cuts, at essay scale: throat-clearing before the claim, sentences that point forward to a payoff, a summary after an example that already landed, a restated payoff. At sentence scale, seven classes: throat-clearing openers, hedges and intensifiers, doublets, empty subjects, nominalizations with filler verbs, redundant modifiers, metaphor stacks and cliches.

The adaptation: choosing the reading method from actual recall

Run the production test. Read the result.

Result                                          Method next time on this kind of text
Claim, supports, and objection all present      Current method is right; do not slow down
Claim present, supports missing                 Intensive read; paragraph test after each block
Claim present, one support inverted             Operator problem; kill-word scan first, restate at each mark
Claim wrong or missing                          Map problem; first-sentence pass, or read the close first
Words decoded, nothing reproducible             Encoding problem; pacing under the line, chunks, a beat per period, subvocalize
Unknown terms blocked the model                 Glossary before the read, not stops mid-sentence

None of these ask you to read faster or to silence the inner voice.
