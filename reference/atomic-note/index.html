Atomic Note

Reference entry · last updated September 4, 2026

Atomic note is a note centered on one idea or knowledge building block.[1] Atomicity concerns conceptual scope. It does not prescribe a word count, file format, or metadata scheme.[2]

The atomicity principle

The atomicity principle directs each note toward one idea.[1] A note can include examples, evidence, and context that serve that idea. The appropriate boundary depends on the intended use, and strict fragmentation can make a note less useful.[2]

  • Precise links: A link can point to a specific claim or concept.
  • Reuse: A focused note can support several projects without carrying unrelated material.
  • Clear scope: A narrow focus helps expose missing context and mixed arguments.

Zettelkasten lineage and terminology

The one-idea-per-note practice belongs to the Zettelkasten lineage. Contemporary Zettelkasten sources describe atomicity as one knowledge building block per note and treat it as a direction for note-making, not a rigid law.[1]

Digital note-makers extended the practice. Andy Matuschak, for example, describes evergreen notes as atomic when each note is about one thing and preserves the context needed to understand that thing.[2] These sources do not establish one person as the inventor of the modern English term atomic note.

Forte calls reusable units of project work Intermediate Packets.[3] His framework describes work as reusable building blocks, but it does not originate the atomic-note term.

Implementation choices

An atomic note needs one clear focus. Other structural features depend on the note system:

  • a title that names the idea or states the note's claim;
  • enough context for the note to remain understandable;
  • links to related notes and sources; and
  • metadata that supports retrieval in a particular tool.

Word limits, progressive summaries, YAML frontmatter, and public URL citations are system-specific conventions. They can support brevity, retrieval, or provenance, but they are not universal requirements for atomic notes.

Linking and reuse

A focused note gives links a precise target. It can be connected across topics and reused in outlines, maps of content, or later writing. Notes that are too broad can blur those links, while notes split too finely can fragment the network.[2]

Relationship to Intermediate Packets

Atomicity classifies a note by conceptual scope. The Intermediate Packet category classifies an artifact by its role in reusable project work. An atomic note can function as an Intermediate Packet when it becomes input to a project.[3]

Intermediate Packets have a wider range of forms:

  • meeting notes and research lists;
  • slides, diagrams, drafts, and templates; and
  • completed deliverables that can contribute to later work.

A packet can contain several ideas. Its defining property is useful reuse in project work.[3]
