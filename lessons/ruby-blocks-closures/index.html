Part 1: blocks

A block is a piece of code passed to a method. Here, each visits every name and runs the block for each one.

Part 2: closures


A closure retains access to variables from its surrounding scope. A lambda is a callable object that can carry that access beyond the method that created it. A block can also be captured as a Proc; here we use lambdas.
